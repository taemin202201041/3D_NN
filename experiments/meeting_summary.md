# 딥러닝 회의용 정리: 크기 줄이기와 성능 올리기

조건: CLEVRER, 학습 영상 2000 / 검증 500 / 테스트 500, 논문식 입력(ResNet-50 2048 x 25프레임, word2vec 300, 4가지 질문 유형), 뉴런 100개, 60 epoch, 검증으로 고른 epoch의 테스트 값. 표의 ± 는 시드 간 표준편차. 원자료는 `results/runs/*.json`, `results/ledger.jsonl`, 요약은 `results/RESULTS.md`.

## 1. 같은 성능으로 더 작게 (효율)

| 방법 | 크기 변화 | 성능 | 근거 |
|---|---|---|---|
| 구조 마스크 A / B2 / B1 (모듈 5개 + 소수 게이트웨이) | 순환 연결 10,000 -> 2,320 / 2,080 / 2,020개 (약 80% 감소) | 전체 정확도 0.447-0.453, full 0.449와 같음 | e08, 시드 3 |
| 같은 마스크의 배선 비용 | 20-21 -> 1.5-2.7 (약 10분의 1) | 위와 같음 | e08 |
| 같은 마스크의 구조 지표 | 모듈성 Q 0.17-0.20 -> 0.61-0.79, small-world 1.3-1.5 -> 3.2-3.8 | 위와 같음 | e08 |
| LSTM 대비 | 파라미터 982,323 -> 247,223 (4분의 1) | 전체 0.448 / 0.449, 서술형 0.376 / 0.379, 같음 | e09, e08, 시드 3 |
| 영상 특징 축소 (선형층 2048 -> 32) | 파라미터 247,223 -> 111,191 (55% 감소) | 전체 0.448 -> 0.454, 서술형 0.379 -> 0.391 (같거나 약간 높음) | e10, 시드 5 |
| 영상 특징 축소 2048 -> 64 | 247,223 -> 179,959 | 전체 0.453, 서술형 0.381 (같음) | e10 |

주의: 마스크는 학습 파라미터 수(247,223)를 줄이지 않고 유효 순환 연결만 줄인다. 파라미터 수가 줄어든 것은 LSTM 비교와 영상 특징 축소다. 특징 축소 층 자체가 파라미터를 만들기 때문에 128, 256차원은 오히려 늘었다(317,495 / 592,567).

## 2. 성능을 올린 것

| 방법 | 효과 | 신뢰도 |
|---|---|---|
| 영상 특징 32차원으로 축소 | 서술형 +1.2점 (0.379 -> 0.391), 예측형(문항 전체) 0.011 -> 0.040 | 약함: 서술형 차이가 시드 편차(0.006-0.007)의 약 2배, 예측형은 여전히 찍기(25%)보다 훨씬 낮음 |
| 학습 데이터 늘리기 (영상 250 -> 2000) | 서술형 테스트 0.356 -> 0.389 (이전 입력: ResNet18, 서술형만) | 중간: 완만하게 계속 오름, 현재 입력으로는 재측정 안 함 |
| position 좌표 학습 | 구조 마스크 있는 조건에서 배선 비용 약 25% 추가 감소 (A 2.7 -> 2.1, B2 2.1 -> 1.5, B1 2.2 -> 1.6), 정확도는 같음 | 약함: 시드 3, 크기가 작음 |

## 3. 성능에 효과가 없었던 것 (사실대로)

- 모델 종류: LSTM, linear RNN, 패널티 없는 ReLU RNN, seRNN 계열 모두 전체 0.445-0.451, 서술형 0.373-0.384로 구분되지 않음.
- 좌표 방식(fixed / position / swap)과 구조(full / A / B2 / B1): 정확도 차이 없음 (0.447-0.453).
- 논문식 입력(ResNet-50, word2vec, 4유형)으로 바꿔도 서술형 0.38 근처로 그대로.
- open_epoch를 1로 앞당긴 것: 정확도 차이 없음, position의 좌표가 실제로 움직이게 되는 효과만 있음.
- 영상 특징 차원 축소로 과적합이 줄지는 않음: 학습 0.59-0.62, 검증 0.45-0.46 간격이 모든 차원에서 같음.

## 4. 이 결과를 해석할 때 꼭 알아야 할 점

- 전체 정확도 0.45는 영상을 전혀 안 쓰는 질문만 모델도 0.450이다. 전체 정확도로는 모델을 구분할 수 없다.
- 영상은 서술형에서만 쓰인다: 영상을 장면끼리 섞으면 서술형이 0.38 -> 0.33으로 떨어지고, 객관식은 변하지 않는다. 기여는 색(질문만 0.11 -> 0.27), 모양, 재질에 집중되고 개수와 존재는 질문만 모델과 같다.
- 객관식(설명, 예측, 반사실)의 문항 전체 정답은 예측형 0.01-0.04로 찍기(25%)보다 낮다. 모델이 보기를 한쪽으로 치우쳐 답하는 것으로 보이며 원인은 아직 확인하지 않았다.
- 질문 벡터는 질문 종류를 100% 구분하므로 질문 쪽은 문제가 아니다.
- 입력 연결이 파라미터의 95% (234,800 / 247,223)다. seRNN 패널티와 마스크는 순환 연결 10,000개에만 걸려서 이 입력 쪽에는 영향이 없다.
- 시드 3-5개라서 정확도 0.5점 이하의 차이는 구분할 수 없다. 배선 비용처럼 차이가 큰 지표만 확정적이다.

## 5. 회의에서 정할 것

1. 서술형만 비교할지, 4유형을 다 볼지 (객관식이 현재 입력으로는 의미 있는 비교가 안 됨).
2. 영상 입력 개선(프레임 수, 공간 특징)을 팀 고정 영역에서 풀지.
3. 데이터를 늘릴지 (논문은 훈련 영상 약 1만 개).
4. 보고할 지표: 같은 정확도에서 배선 비용, 모듈성, small-world.
