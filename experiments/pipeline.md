# 현재 파이프라인 (2026-11-16 기준)

코드 위치는 experiments 폴더이고, 실험 설정은 config/*.json, 결과는 results/ 에 있어요.
원래 코드로 돌아갈 수 있도록 바꾸기 전 파일은 backup_code_20261111/ 에 백업해 뒀어요.

```
[입력: 영상 쪽]  ← 우리 베이스라인 (논문과 비교할 쪽)
  CLEVRER 영상 15000개 (128프레임)
    -> 25프레임 균등 추출
    -> ResNet-50 (ImageNet 고정, 학습 안 함)
    -> 프레임당 2048개 숫자  [25 x 2048]
       (make_features_r50_all.py -> data/clevrer_paper/features_r50_all.npy)

[입력: 주석 쪽]  ← 진단용 (논문은 안 씀)
  CLEVRER 주석 JSON 15000개
    -> 25단계 x 물체 6칸 x 37특징 = [25 x 222]
    -> 정규화, 없는/화면 밖 물체는 0
       (perception.py AnnotationPerception)

[질문 쪽] (4가지 중 하나를 선택해 비교)
  질문 + 보기(객관식은 보기마다 1샘플)
    A. 평균 벡터  : word2vec 평균 (300)             <- 원래 방식
    B. positional : 단어별 벡터를 위치별로 이어붙임   <- 새로 추가, LSTM 없음
    C. seq_core   : 단어를 코어에 순서대로 먼저 넣음   <- 새로 추가
    D. program    : 풀이 프로그램 토큰 개수 (팀 방식) <- 진단용

                 입력[25 x D] + 질문 벡터(매 단계 붙임)
                              |
                              v
        코어: seRNN 100뉴런 (5x5x4 격자, 3D 좌표)
          - 순환 가중치 W, 입력 가중치
          - 손실 = 과제 손실 + 공간 패널티(연결 x 거리 x 소통성)
          - 좌표 이동: fixed / position / swap / relayout
          - 구조 마스크: A / B2 / B1 (게이트웨이 4/2/1)
                              |
                              v
        마지막 은닉상태 -> 선형 읽기 -> 23개 클래스
          - 답 마스크: 문제 유형별로 가능한 답만 허용
                              |
                              v
평가: 서술형 정확도 / 객관식 보기별 / 객관식 문항 전체 정답
      4유형: 서술형, 설명, 예측, 반사실

비교 모델: LSTM, 선형 RNN, 질문만(영상 끔), 패널티 없는 ReLU RNN
분할: 학습 0-8999 / 검증 9000-9999 / 테스트 10000-14999
```

## 표시해 둘 것
- 입력은 영상 또는 주석 중 하나이고, 질문은 항상 들어가요. 둘을 같이 넣지는 않아요.
- 주석 입력은 진단용이에요. 논문은 주석을 안 쓰니까 최종 비교에는 영상 쪽만 써요.
- 분할 0-8999 / 9000-9999 / 10000-14999는 제가 정한 거예요. 팀 PDF는 학습 0-9999, 테스트 10000-14999라서 검증을 어디서 떼는지는 팀에 확인이 필요해요.
- 질문 인코딩 B, C는 진단용 실험이에요. 팀 합의 없이 기준으로 바꾸지 않아요.
- LSTM은 비교 대상이라 질문 읽기에 쓰지 않아요.
